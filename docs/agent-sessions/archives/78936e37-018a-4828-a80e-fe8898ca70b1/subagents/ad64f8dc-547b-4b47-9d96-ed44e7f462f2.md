**What OK does (`modalSalvar` flow):**
1. `_salvarEstadoModal(modal)` — reads each `.kcfg-ex-card` field (`nome`, `series`, `reps`, `tecnicas`, etc.) into `_kinevoExerciciosAtual[idx]`.
2. `_renomearDivisaoModal(modal)` — updates `dia_treino` on all exercises of that division + `_kinevoRotulosDivisao`.
3. Collects session state:
   - `modal._sessionSupersets` — supersets created in this session
   - `modal._sessionNovosIds` — new exercise row IDs
4. If supersets pending → `_mostrarDialogSemanas(...)` → `_propagarSupersetParaSemanas(sid, semanasAlvo)`.
5. If new exercises with name → `_mostrarDialogSemanas(...)` → `_propagarAdicaoExercicioParaSemanas(ex, semanaOrigem, semanasAlvo)`.
6. Else → `finalizarModal()` → close session + `renderEditorVisualExercicios([..._kinevoExerciciosAtual])`.

**Does NOT persist to Firestore on OK** — only updates in-memory state, localStorage (`_salvarEditorLocalStorage`), and hidden JSON field (`_syncJsonSilencioso`).

**What `bmApply` does:**
1. Collects checked exercises + field mods (`series`, `reps`, `intervalo`, `tecnicas`, etc.).
2. Builds `alvosSemanaAtual` via `_montarAlvoExercicio` (uses `id_referencia`, not array index).
3. Applies `_aplicarModsEmEx(ex)` **immediately on current week** selected rows.
4. Closes bulk modal.
5. If `semanas.length > 1` → `_mostrarDialogSemanas` with title `"Edição em massa - quais semanas?"`.
6. On confirm (`wConfirm` / "Aplicar"):
   - Resolves `semanasAlvo` from scope:
     - `current` → `[_kinevoSemanaAtiva]` only (Somente nesta semana)
     - `all` → all weeks
     - `forward` → current + following
     - `specific` → checked checkboxes
   - For other weeks (`semanasAlvo.filter(s => s !== _kinevoSemanaAtiva)`), finds homologs via `_matchAlvoExercicio` and applies same mods.
7. `renderEditorVisualExercicios(_kinevoExerciciosAtual)`.

**Bulk delete** (`bmExcluirSelecionados`, ~L3876) uses the same week dialog pattern with title `"Excluir exercício(s) — quais semanas?"`.

## 3. Week/workout state structure

### In-memory globals (`app.js` ~L1928–1940)

```javascript
let _kinevoExerciciosAtual = [];      // flat array — source of truth
let _kinevoFaseAtiva = null;
let _kinevoDiaAtivo = null;             // e.g. "Treino A"

```

### Exercise object shape (`_criarExercicioBase`, ~L2080)

Each row in `_kinevoExerciciosAtual` is a flat object:

| Field | Role |
|-------|------|
| `semana_num`, `semana_label` | Global week |
| `fase`, `mesociclo_label` | Mesocycle label |
| `dia_treino` | Division key (e.g. `"Treino A"`) |
| `ordem` | Order within week+day |
| `exercicio_id` / `id` | Unique row ID |
| `id_referencia` | Logical slot ID across weeks (propagation key) |
| `nome`, `series`, `reps`, `intervalo`, `foco`, `observacoes`, … | Exercise data |
| `superset_id`, `tecnicas[]` | Grouping / techniques |

**Hierarchy is derived, not nested:** week tabs → day tabs → flat filtered list.

- Weeks: `_extrairSemanasEDias()` → `{ semanas, diasPorSemana }`
- Divisions per week: `_listaDivisoesSemana(semana)` (~L2282)
- Filter: `_exercicioNaSemana(ex, semana)` + `_mesmoDiaTreino(ex, diaAtivo)`

## Save: Configurar treino OK vs Edição em massa

| Aspect | **Configurar treino OK** | **Edição em massa Aplicar** |
|--------|--------------------------|-----------------------------|
| **Scope** | Exercises in current week+day modal | Selected exercises across all days of current week |
| **Write path** | DOM → `_salvarEstadoModal` → `_kinevoExerciciosAtual` | `_aplicarModsEmEx` on selected indices |
| **Current week** | Always saved on OK | Applied before week dialog |
| **Cross-week** | Only for **new exercises** or **new supersets** in session | For **field updates** on homologous exercises |
| **Matching** | ADD: `_propagarAdicaoExercicioParaSemanas` (append, dedupe by `id_referencia`/name) | UPDATE: `_matchAlvoExercicio` by `id_referencia` → name → ordem |
| **Week dialog** | `"Adicionar exercício — quais semanas?"` or superset variant | `"Edição em massa - quais semanas?"` |
| **"Somente nesta semana"** | `wscope=current` → no cross-week propagation | Same — current week already modified; other weeks skipped |
| **Re-render** | `renderEditorVisualExercicios` in `finalizarModal` | `renderEditorVisualExercicios` after propagation |
| **Firestore** | Neither path writes Firestore directly | Same |

Both paths ultimately mutate `_kinevoExerciciosAtual`, then `renderEditorVisualExercicios` syncs localStorage + `#treinoExerciciosJson`. Firestore save is separate via `_persistirExerciciosEditorSilencioso` (~L3597) / explicit "Salvar ficha" flow.
